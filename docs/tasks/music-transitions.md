# Combat music transitions

**Status:** design
**Branch:** main
**Worktree:** none
**Goal:** In the music lab and in a `battle` fight, the combat score moves between sections with no transition a listener can pick out as a cut. The user confirms this by ear in the lab on both songs. Useless if: transitions are smooth only because the score stops changing sections; seams pass a numeric check but still sound like edits; the fix covers today's two songs but the next song added through prep brings the same cuts back.
**Mode:** interactive
