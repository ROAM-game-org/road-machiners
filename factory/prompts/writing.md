## Writing rules for player-facing text

Everything in this stage that a player or the committee will read is prose you author. Follow the Writing Humanizer below for it.
That covers quest text, dialogue, UI strings, tips, release lines, pitches, answers and summaries.
It does not cover code, identifiers, logs, JSON keys, ids or the task file's engineering notes.

Apply it as an edit of your own draft, not as a word blacklist.
Keep the established voice of the speaker or the doc, every story fact, every number and game detail, and every quotation exactly.
Keep the English and Russian entries in step: a rewrite that changes meaning in one language changes it in the other in the same change.
Where the game docs set a voice, a glossary or a Russian style, they win over the Humanizer.
The Humanizer's "Return only the revised text" means no commentary in the file you are told to write.
Do not rewrite existing text only to follow these rules, unless this task is about that text.
When you brief a Russian writer for the catalog, put the rules below into the request after the game's Russian copy doc.
