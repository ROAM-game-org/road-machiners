# Character lines

Every line a named character says is generated by another model speaking as that character, one call per line. The agent then edits the result and puts it in the quest. Models imitate voices well, and a separate call per line keeps each person from sounding like the writer of the scene.

## When to use it

Use it for every spoken line of a named person, in quests, talk hubs and page scenes. Narration, choices, notes and UI text stay with the agent. A minor speaker with one job can skip it.

## The call

English goes to codex and Russian goes to agy. Claude never writes a character line or any Russian text.

- English: pipe the prompt to `codex exec -s read-only --skip-git-repo-check --ephemeral -o <out file> -`.
- Russian: `agy --dangerously-skip-permissions -p "<prompt>"`. [Russian copy](russian.md) has the model flags.
- Check the exit code of every call. A failed call writes nothing, and agy can hit a quota that lasts days. Report the lines that are missing, and never fill them in by hand.
- Independent lines can run in parallel. Keep scratch prompts and outputs in `tmp/`.

## The prompt

One shape, always:

```
<one line about the game>

Write a piece of dialogue from the character's POV for our game.
Character: name, key aspects, how they speak, a small sample of speech
Context: short facts this character knows right now
What to speak about: brief raw description of what they should say
Reply:
```

Fill each part like this.

- Game line: one sentence on the setting and tone, the same for every call.
- Character: copy the person's sheet from [Voices](../lore/voices.md), and the aspects from [Characters](../lore/characters.md) when they have an entry. Add two to four sample lines. For Russian, say to reply in Russian and paste the names from the glossary in [Russian copy](russian.md).
- Context: only what the character knows at this moment, and the question the player asked. No plot, no other branches, no game words.
- What to speak about: raw facts and the order to say them in. Add the length wanted. Do not give wording, because wording is the model's job.

## Keep voices apart

- A sample teaches by repetition. If every sample has the same joke or the same pet word, every line will carry it. Use samples that show the speech rule in different ways.
- Do not tell the model to always do a habit. Say a habit happens sometimes, or the model will do it in every line.
- Say that the character never invents named people or relatives that the facts do not give.
- Read the first batch for tics before you use any of it. Count how many lines share a joke, a pet word or a sentence shape. If more than a few do, change the prompt and run the batch again.

## Edit the result

The model gives raw material. Before it goes in the quest:

- Check every fact against the lore and the facts you gave. Cut anything the model invented.
- Cut the length to what the scene needs.
- Cut a tic that repeats from the line before, even if the model liked it.
- Remove words that agree with the gender of the player, and any count of years.
- Keep the voice. Fix rhythm and wording only. Do not smooth it into your own style.
- Read the line with the name hidden. If another sheet could own it, run the call again with a sharper character part.

Then check against [Writing dialogue](dialogue.md) and the rules in [Writing quests](quests.md).
